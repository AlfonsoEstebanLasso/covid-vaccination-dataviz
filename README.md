## Objective

Explore global COVID-19 vaccination progress through interactive visualizations. The notebook formulates five analysis questions and answers each one with an interactive Plotly chart, from animated world maps of vaccination rates to an assessment of how consistently each country reported its data.

The five questions addressed in the notebook:

1. Which vaccines were most used per country and year? (animated choropleth maps for 2020, 2021 and 2022)
2. How did the monthly vaccination rate evolve across continents? (multi-line time series)
3. Which reporting organizations registered the most fully / partially vaccinated people, and where? (stacked bar charts per continent)
4. Which countries administered the most / fewest doses relative to their population? (pie charts of the top and bottom 50 countries)
5. How consistently did countries report their data? (missing-data box plots and a bubble scatter over time)

## Data

**Dataset:** [COVID-19 World Vaccination Progress](https://www.kaggle.com/datasets/gpreda/covid-world-vaccination-progress) — published on Kaggle by Gabriel Preda, compiled from [Our World in Data](https://ourworldindata.org/covid-vaccinations) (OWID data is licensed CC BY 4.0).

The CSV files are **not** included in this repository — download `country_vaccinations.csv` from the Kaggle page above. Its columns:

| Column | Description |
|---|---|
| `country` | Country name |
| `iso_code` | ISO 3166-1 alpha-3 country code |
| `date` | Observation date |
| `total_vaccinations` | Cumulative doses administered |
| `people_vaccinated` | People with at least one dose |
| `people_fully_vaccinated` | People with a full vaccination scheme |
| `daily_vaccinations_raw` | Raw daily doses (dropped during cleaning) |
| `daily_vaccinations` | Smoothed daily doses |
| `total_vaccinations_per_hundred` | Doses per 100 inhabitants |
| `people_vaccinated_per_hundred` | Vaccinated people per 100 inhabitants |
| `people_fully_vaccinated_per_hundred` | Fully vaccinated people per 100 inhabitants |
| `daily_vaccinations_per_million` | Daily doses per million inhabitants |
| `vaccines` | Vaccines used in the country |
| `source_name` | Reporting organization |
| `source_website` | Source URL (dropped during cleaning) |

## Methods

- Data cleaning with **pandas**: column pruning (`daily_vaccinations_raw`, `source_website`), date parsing, and per-column null/empty counts; the cleaned table is saved as `country_vaccinations_procesado.csv`.
- Continent assignment from ISO codes with **pycountry_convert**.
- Interactive charts with **Plotly Express**: animated choropleths, line charts, stacked bars, pie charts, box plots with range sliders, and a bubble scatter with time-range selectors.
- Each figure is exported as a standalone HTML file (Plotly.js embedded).

## How to run

1. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Download `country_vaccinations.csv` from the [Kaggle dataset page](https://www.kaggle.com/datasets/gpreda/covid-world-vaccination-progress).
3. Open `PRI_Visualizacion_datos.ipynb` (Jupyter or Google Colab) and set the `PATH` variable near the top to the folder containing the CSV. The original run used a Google Drive mount, so the first cell (`google.colab.drive`) can be skipped outside Colab.
4. Run the cells in order. The cleaning steps write `country_vaccinations_procesado.csv`, which the visualization cells read back; each chart is also saved as an HTML file in `PATH`.
